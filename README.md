# rb-dance-v2

Rhythmic Beat Dance Court website for dance and fitness classes in Chennai.

Designed and developed by Mohan.

## Development

```sh
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```sh
npm run build
npm run start
```

Built with Next.js 16, React 19, TypeScript, CSS Modules, GSAP, and Lenis.
